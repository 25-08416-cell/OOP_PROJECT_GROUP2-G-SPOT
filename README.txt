G SPOT TRACKER

Standalone browser-based cycle and pregnancy health tracker.

PROJECT STRUCTURE
- DATABASE/  Reserved for database scripts and schemas.
- backend/   Reserved for server-side code and APIs.
- frontend/  Current standalone web application.
- run.bat    Opens the app on Windows.
- run.sh     Opens the app on Linux.

HOW TO RUN
Windows: Double-click run.bat, or open frontend/G-SPOT-tracker.html.
Linux: Run chmod +x run.sh, then ./run.sh.

The supplied app currently stores data in browser localStorage. It does not currently use an external database or backend. DATABASE/ and backend/ are placeholders included to match the requested repository layout.
